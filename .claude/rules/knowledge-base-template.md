## 识别设定(DID 四分组 × 距离带)

- **处理**:城市公共数据开放平台上线(事件时间)
- **异质性四分组**(跨边界配对):
  1. 双边开放(上游开 + 下游开)
  2. 单边开放(上游开,下游不开)
  3. 单边开放(上游不开,下游开)
  4. 均不开放(对照组)
- **距离梯度**:边界不同距离带的环境质量变动【距离带切点待研究设计确认】
- **企业迁移维度**:新增企业(是否污染企业)、污染企业退出与再落户(距边界远近、落户地数据开放与否、环境规制强度)
- **推断**:默认城市层级聚类;事件研究/平行趋势检验必做
- **待解决的设计问题**:边界配对定义(相邻市对?省对?)、溢出(SUTVA)处理、平台「试运行」日期认定

## 领域陷阱(编码与设定)

| 陷阱 | 影响 | 应对 |
|------|------|------|
| 监测站搬迁/数据断点 | 虚假污染变化 | 站点层面平衡检查 |
| 企业注册地 ≠ 经营地 | 迁移指标失真 | 用经营地/纳税地口径 |
| 距离带内生性(边界两侧特征差异) | 识别偏误 | 平衡性检验、带宽敏感性 |
| 污染跨行政区传输(溢出) | SUTVA 违反 | 风向/水系加权、稳健性设定 |
| 平台「试运行」日期错定 | 事件时间错 | 官网公告与 API 首日交叉验证 |
