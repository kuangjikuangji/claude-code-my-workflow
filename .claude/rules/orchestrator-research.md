# 研究项目编排器(简化版)

**适用于数据清洗、回归分析、模拟等代码工作** — 用此简化循环替代全量多代理编排。

## 简化循环

```
计划批准 → 编排器启动
  │
  第 1 步:实施 — 执行计划步骤
  │
  第 2 步:验证 — 运行代码,检查输出
  │         Python:python3 运行无错误、输出文件非零字节
  │         Stata:log 无 r(错误)、e(N)/assert 通过、表格导出
  │         验证失败 → 修复 → 再验证
  │
  第 3 步:评分 — 按 quality-gates 评分表
  │
  └── 分数 >= 80?
        YES → 完成(用户示意后提交)
        NO  → 修复阻塞项,再验证,再评分
```

**无 5 轮循环。无多代理评审。只是:写、测、完成。**

## 验证清单

- [ ] Python 脚本运行无错误
- [ ] Stata log 无 r(错误)
- [ ] 无硬编码绝对路径(头部路径块除外)
- [ ] 随机成分有 seed
- [ ] 输出文件在预期路径生成
- [ ] 容差对账通过(如适用)
- [ ] 质量分 >= 80
